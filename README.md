<h1 align="center">BarryScoreboard</h1>

<p align="center">
  A simple Vue 3 PWA for managing tournament brackets and tracking match scores.
</p>

<p align="center">
  <a href="https://tm-barry.github.io/barry-scoreboard/">
    https://tm-barry.github.io/barry-scoreboard/
  </a>
</p>

---

## Features

- Tournament bracket creation and management
- Scoreboard with timer to track game progress
- Installable as a PWA
- Offline support

## Getting Started

```bash
# Development
npm install
npm run dev

# Build
npm run build
npm run preview
```
